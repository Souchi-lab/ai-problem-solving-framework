# SoChi BLOCKS — Context

## プロジェクト概要

SoChi BLOCKS は、ブロック系パズルゲームを中心とした Web ベースのプロダクトである。

ユーザーはブラウザ上でパズルを楽しみながら、空間認識・論理思考・創造性を鍛えることができる。
教育・娯楽・習慣形成の交差点を狙ったプロダクトとして設計されている。

---

## プロジェクト構造（ミニスタートアップ）

SoChi BLOCKS は少人数（〜個人）で複数の機能レイヤーを担当する、
典型的なミニスタートアップ構造を持つ。

| レイヤー | 内容 |
|---|---|
| **Engineering** | Web アプリの開発・パフォーマンス・インフラ |
| **Design** | UI / UX / ビジュアルデザイン / ユーザーフロー |
| **Algorithm** | パズル生成ロジック / 難易度設計 / 解析 |
| **Content** | ゲーム説明 / ヘルプ / 教材 / ブログ / SNS投稿 |
| **Marketing** | SNS運用 / LP / SEO / ユーザー獲得・リテンション |

各レイヤーで発生する問題を、このフレームワークで横断的に解決することを目指す。

---

## 現状の技術スタック（参考）

- フロントエンド: React ベース（Web アプリ）
- パズルデータ: 静的 / 動的生成の混在
- 展開: Web（モバイル対応含む）

※ スタックの詳細は run ごとの `context.md` または `goal.md` で補足する

---

## 実験環境としての価値

1. **再現性テスト**: 同じ問題に対して複数の AI agent を試した場合の比較ができる
2. **ドメイン分離テスト**: Engineering 問題と Content 問題を同じフレームワーク構造で解けるか
3. **ループ効率テスト**: 1 ループあたりの実質的な改善量を蓄積して可視化できる
4. **汎化の足がかり**: ここで機能したパターンを業務DX・SNS運用・教材作成へ横展開できる
