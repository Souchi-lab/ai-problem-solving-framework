## What Changes / What Stays

### 変わるもの
- `framework/` 直下の安定ドキュメントが `core/` サブディレクトリへ移動
- `framework/agents/`, `templates/`, `workflow/` が `legacy/` サブディレクトリへ移動
- `src/apsf/` のABC/domain モデルが `core/` へ、実装群が `legacy/` へ分離

### 変わらないもの
- `runs/` — run ログは変更対象外
- `framework/experimental/` — 再設計パッケージは元の場所に残る
- `src/apsf/viewer/` — 独立サポート層として現位置維持
- `docs/` — SoChi BLOCKS 成果物・比較ドキュメント
- `tests/` — 現行テスト群（移行後に更新するが移行前提条件ではない）

---

## Parallel Operation Policy

移行 run が完了するまで、現構造と提案構造の両方を comparable に保つ。

- 現行 APSF は `legacy/` 層として runnable かつ readable
- 新規 run は引き続き `runs/` に蓄積される
- 設計ドラフトは `experimental/` に留まり、正式採用前に参照・比較可能
- 比較ドキュメントは `docs/compare/` に蓄積され、設計判断の根拠として残る
