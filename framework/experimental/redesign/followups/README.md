# Follow-up Packages

This directory contains small follow-up packages that are attached to an
existing parent series.

These packages are intentionally narrower than the main reconstruction design
package. They are meant to test local questions without re-expanding into broad
redesign work.

## Current Packages

- `sochi-first-question-entry/`
  Examines whether a user can enter the first playable question without reading
  the how-to-play page first.
- `sochi-easy-first-look/`
  Examines whether "easy" puzzles actually function as first-look, beginner
  friendly entry problems.

## Usage

Use these packages as trial follow-up variants.

Each follow-up should stay narrow, preserve its parent-series context, and end
with a result that records:

- what is now stable
- what remains conditional
- what should trigger the next follow-up
