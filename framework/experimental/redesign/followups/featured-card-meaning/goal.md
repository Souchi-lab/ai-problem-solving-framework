# Goal
---
## Objective

Clarify what the featured card means and why the user should care about it.

This follow-up should make the role of the featured card easier to understand without redesigning the whole top page.

## Scope

- featured / today's puzzle card on the top page
- label, subtitle, and small meaning cues
- user understanding of why this card is surfaced

## Non-Goals

- full top-page redesign
- recommendation system redesign
- progress system redesign
- puzzle list restructuring

## Success Criteria

1. The current ambiguity around the featured card is described precisely.
2. It is clear whether the issue is label, meaning, or duplication with nearby surfaces.
3. The proposed fix stays local to the featured card surface.
4. It is clear whether the gain comes from copy, emphasis, or no change.

## Expected Output

- a narrow `plan.md`
- if needed, a small `build.md`
- a `result.md` that records the exact meaning clarification path

## Notes For Planner

Start by checking:

- what the featured label currently implies
- whether users can tell why this card is highlighted
- how it differs from first-puzzle and puzzle-list surfaces

The key question is not "how to improve the whole homepage."
It is "what is the smallest change that makes the featured card feel intentional."
