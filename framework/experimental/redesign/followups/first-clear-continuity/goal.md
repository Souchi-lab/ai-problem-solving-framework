# Goal
---
## Objective

Improve continuity immediately after a user's first clear so that "solve one puzzle" more naturally turns into "try one more."

This follow-up should focus on the narrowest possible post-clear continuity improvement.

## Scope

- first-clear / just-cleared experience
- continuity cues immediately after success
- existing post-clear surfaces such as overlay / next action area

## Non-Goals

- full progression system redesign
- achievement / streak system
- recommendation engine expansion
- top-page navigation overhaul

## Success Criteria

1. The current first-clear continuity gap is described precisely.
2. The main post-clear surface is identified.
3. The fix stays narrow and local to the post-clear experience.
4. It is clear whether the continuity gain comes from copy, emphasis, or a small action-path adjustment.

## Expected Output

- a narrow `plan.md`
- if needed, a small `build.md`
- a `result.md` that records the exact continuity path chosen

## Notes For Planner

Start by checking:

- what the user sees right after clear
- whether the "next" action is visible enough for a first-time player
- whether the gap is caused by missing action, weak emphasis, or competing buttons

The key question is not "how to redesign victory."
It is "what is the smallest change that makes one-more-puzzle feel natural."
