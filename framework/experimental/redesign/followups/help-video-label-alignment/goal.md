# Goal
---
## Objective

Align the expectation created by "watch a video" style help labels with the actual destination the user reaches.

This follow-up should determine whether the mismatch can be resolved by:

- copy only
- link-target adjustment
- or a small combination of both

Then it should define the narrowest implementation path.

## Scope

- top-page and help-entry surfaces related to "video" / "how to play" guidance
- expectation created by the label
- actual destination reached after click

## Non-Goals

- full help-system redesign
- tutorial video production
- viewer interaction redesign
- broad navigation restructuring

## Success Criteria

1. The current mismatch is described precisely.
2. The candidate fix is narrowed to the smallest plausible path.
3. It is clear whether this is a copy fix, a destination fix, or both.
4. The follow-up stays local to the help/video entry path.

## Expected Output

- a narrow `plan.md`
- if needed, a small `build.md`
- a result that records the chosen alignment path

## Notes For Planner

Start by checking:

- what the current label promises
- where the click actually goes
- whether users are being sent to a text help page while expecting a video

The key decision is not "how to improve help in general."
It is "how to remove the mismatch with the smallest possible change."
