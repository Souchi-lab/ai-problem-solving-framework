# Goal

---

## Follow-up Context

- Parent series:
  SoChi BLOCKS 初回体験改善
- Previous result:
  first playable moment を優先する方針と、follow-up を narrow question で回す型はすでに確認済み
- New trigger:
  トップページが「説明する」構成に寄っており、最初の1問へ入る導線が広く重く見える
- Scope limit:
  トップページの CTA 整理と first-playable 導線の明確化のみ
- Non-goals:
  onboarding 全体 redesign / 実装 / 遊び方ページ全面改修 / ビジュアル全面刷新

---

## Goal Statement

SoChi BLOCKS のトップページについて、
`まず1問やってみる` を主 CTA、
`遊び方を見る` を副 CTA とする構成へ整理したとき、
初見ユーザーが迷わず最初の1問へ入れる導線として成立するかを確認する。

今回の follow-up は、
トップページ全体を作り直すことではなく、
CTA の主従関係とその周辺の情報配置を絞って見直すための narrow run とする。

---

## Background

これまでの follow-up で、
SoChi BLOCKS の初回体験では
`説明量` より `迷わず最初の1問に入れること`
を優先すべきという整理が見えている。

一方で現状のトップページは、
説明・導線・ストーリーが同じ面の中で競合しやすく、
初見時に
`何を最初に押せばよいか`
がやや分散して見える可能性がある。

そのため今回は、
主 CTA を `まず1問やってみる` に固定し、
`遊び方` は補助導線へ下げることで、
トップページを
`説明するページ`
より
`遊ばせる入口`
として整理できるかを確かめる。

---

## Success Criteria

1. 主語が最後まで
   `トップページの CTA 整理`
   に留まっている
2. 主 CTA と副 CTA の役割分担が明確になっている
3. `同じ意味の導線を何度も出さない`
   という方針が構成上で守られている
4. トップページが
   `説明中心`
   ではなく
   `最初の1問へ入る入口`
   として再構成されている
5. `遊び方` は必要な補助導線として残しつつ、
   主導線の邪魔をしない位置づけになっている
6. result で
   `この変更が初見の迷いを減らしそうか`
   を narrow に評価できる形になっている

---

## Expected Outputs

- 改善後のトップページ構成案
- 主 CTA / 副 CTA の役割定義
- 各主要セクションの見出しと本文の改善文言
- scope 外へ広げないための boundary

---

## Non-Goals

- 遊び方ページ全体の再設計
- SoChi BLOCKS 全体の IA 再設計
- UI 実装そのもの
- visual design system の全面刷新
- 難易度設計やゲームルールの変更

---

## Constraints

- `まず1問やってみる` を主 CTA とする
- `遊び方を見る` は副 CTA に留める
- トップページ内で同じ意味の導線を繰り返さない
- 作者ストーリーは残してよいが、主要導線の邪魔をしない位置に置く
- 情報量の多さではなく、
  `迷わなさ`
  を親切さの基準にする

---

## Notes For Planner

- 最重要判断は
  `何をトップの first action にするか`
  である
- CTA 文言だけでなく、
  その周囲の情報配置も
  `主 CTA を押しやすくするか`
  で見る
- `説明するサイト`
  に戻らないこと
- `遊び方ページも直したい`
  という論点は今回は scope 外へ退避する
- 必要なら
  `ゴール条件の先出し`
  `3ステップ図解`
  `操作の分離`
  は主 CTA を支える要素として扱う
- 現状のトップページは hero セクションに CTA が複数並列しており、
  `まず何を押すか` が視覚的に優先されていない
