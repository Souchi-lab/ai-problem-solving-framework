# Goal

---

## Goal Statement

軽量 follow-up 運用の実地検証として、
Twitter 投稿のタグ改善を題材に、
現行 4 点セット（goal / plan / review / result）が
軽量タスクでも過剰にならずに回せるかを確かめる。

今回の目的は二層になっている。

- 表層: Twitter 投稿のタグ構成を改善する
- 裏層: 軽量タスクに対して現行 follow-up 形式が適切か測る

どちらか一方ではなく、この2つを同時に達成することが今回の run の意図である。

---

## Background

これまでの redesign 系では、
構造整理・mapping・classification まで設計が進んだ一方で、
実 repo にはまだ何も着地していない状態が続いていた。

Claude・ChatGPT・Codex の見解が揃い、
「次の価値は設計を増やすことではなく、1本だけ実物を動かして確かめること」
という方向が出た。

そこで今回は、

- 変更範囲が小さく失敗コストが低い
- 効果が数値や実感として見えやすい
- 現行 follow-up の型と比較しやすい

という条件を満たす Twitter タグ改善を実験台として選んだ。

今回は「別形式を試す」のではなく、
現行 4 点セットがどこまで軽い題材に耐えられるかを測る試験として位置づける。

---

## Success Criteria

今回の goal は、次の条件を満たす状態になること。

1. 改善対象が「Twitter 投稿のタグ構成」に限定されている
2. 題材を軽量タスクに固定したまま、形式は現行 4 点セットで通せる
3. 「重すぎた / ちょうどよかった / 足りなかった」を
   result 時点で判断できる観点が定義されている
4. SNS 戦略全体の見直しに広がらない
5. この follow-up が軽量 variant 検討の比較基準として使える状態になっている
6. 後続の plan で、改善対象・非対象・形式評価観点を切り分けられる形になっている

---

## Expected Outputs

この run で目指す出力は次である。

- Twitter タグ改善のスコープ定義
- 現行 4 点セット適用方針の確認
- この follow-up で扱うこと / 扱わないこと
- result で形式の重さを評価するための観点
- 後続 plan に渡せる整理

---

## Non-Goals

今回の run では次はやらない。

- SNS 戦略全体の見直し
- 投稿頻度・時間帯・コンテンツ方針の変更
- follow-up 形式の簡略化（それは result 後に判断する）
- Twitter 以外の SNS への展開
- 実装・投稿の実行

---

## Constraints

- scope は Twitter 投稿のタグ構成に限定する
- 形式変更は今回行わない（現行 4 点セットを維持する）
- 軽量タスクとして扱い、新しい抽象系列に膨らませない
- 形式評価の結論は result まで保留し、goal / plan 段階で先走らない

---

## Notes For Planner

Planner は次を明確化すること。

- 現状のタグ構成と改善の方向性（何が足りて何が足りないか）
- 改善効果をどう確認するか（定性 / 定量の最小基準）
- 4 点セットの各フェーズで何を判断するか
- result で「形式の重さ」を評価するための観点の定義

特に、
「タグを増やすこと」と「タグ改善の効果を確かめること」は
同じではないことを区別すること。

また、
何をもって「重い / ちょうどよい / 足りない」とみなすかを
次の4観点で定義すること。

- 作業量: 各フェーズで実際に手を動かす量は適切か
- 判断量: 各フェーズで求められる判断の数・難度は適切か
- 文書量: 書く量が題材の軽さに対して過剰になっていないか
- 効果の見えやすさ: result 時点で改善効果が確認できる状態になっているか
