# Goal

---

## Goal Statement

SoChi BLOCKS の動画冒頭演出として、
「散らばったピースが集まって直方体になる」アニメーションを
既存パイプライン上で試作し、
初見理解フックとして機能するかを確かめる。

今回の目的は動画全体の再設計ではなく、
冒頭数秒の演出差分を既存パイプラインの範囲で実装・評価することである。

---

## Background

`generate_puzzle_video.py` は matplotlib + ffmpeg の自動パイプラインで、
ピースを3D空間で座標制御するアニメーションフェーズが実装済みである。

現在の冒頭演出はパズルを即表示（INTRO_FRAMES）または
上空から降下（FLOAT_FRAMES）の形をとっている。

「散らばったピース → 集合 → 直方体」演出は、
既存の座標補間の仕組みを流用できるため、
新規3D基盤や外部ツールを必要としない。

また、twitter-tag-improvement follow-up で
4点セットが「実装を伴わないタスク」に対して機能することを確認した。
今回は「小さめの実装を伴う small follow-up」として、
同じ形式がどこまで使えるかも合わせて見る。

---

## Success Criteria

今回の goal は、次の条件を満たす状態になること。

1. 改善対象が「冒頭演出の差分実装」に限定されている
2. 既存パイプライン（`generate_puzzle_video.py`）の範囲で試作できることが前提になっている
3. 評価観点が次の3点に絞られている
   - 初見で完成形（直方体）が伝わるか
   - 続きを見たくなるか
   - ネタバレになりすぎないか
4. 動画全体の再設計・新規3D基盤に広がらない
5. 試作対象が「1本の冒頭演出バリアント」に限定されている
6. result で「この演出は採用に値するか」を判断できる観点が定義されている

---

## Expected Outputs

この run で目指す出力は次である。

- 冒頭演出の差分実装（既存パイプライン上）
- 試作動画 1本
- 3観点による評価
- 4点セットの形式評価（実装を伴うタスクへの適合度）

---

## Non-Goals

今回の run では次はやらない。

- 動画全体の構成変更
- 新規3D描画エンジンの導入
- 複数バリアントの同時試作
- TikTok / Instagram 向けの個別最適化
- 演出の最終採用決定

---

## Constraints

- 実装は `generate_puzzle_video.py` の既存フェーズ差分に留める
- 試作は1本に絞る（複数バリアントは result 後に判断）
- 評価は3観点で行い、広げない
- 演出採用の最終判断は result 後に行う

---

## Notes For Planner

Planner は次を明確化すること。

- 「散らばった状態」の定義（ピースの開始位置をどう決めるか）
- 「集まる」アニメーションの実装方針（既存フェーズのどこに差し込むか）
- 試作1本の完了条件
- 3観点の評価をどう行うか（自己評価 / 視聴テスト / 定性判断）
- 形式評価の観点（実装を伴うタスクで4点セットは適切だったか）

特に、
「初見で完成形が伝わる」と「ネタバレになりすぎない」は
トレードオフになりうるため、
どちらを優先するかの基準を plan で明確にすること。
